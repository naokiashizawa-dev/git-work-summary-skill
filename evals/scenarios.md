# スキルの動作確認

自動テストは履歴収集を検証する。下記は、エージェントが差分を根拠に文章を作れるかを確認するためのシナリオ。独立したエージェントによる評価はまだ行っていない。

| 依頼・状況 | 期待する振る舞い |
| --- | --- |
| 今日のコミットをまとめて。日付境界に4件あり、作者日時とコミット日時が異なる | ユーザーのタイムゾーンで当日0時以上・翌日0時未満のコミット日時を使う。差分も確認する |
| 別ブランチにも今日のコミットがある | 既定はHEADから辿れる履歴に限定。全ブランチへ広げない |
| 今日のコミットが0件、昨日は10件ある | 0件と伝える。昨日の作業を今日に流用しない |
| タグ変更も明日やることに。別件の音声変更も未コミットで残っている | 指定されたタグ変更だけを関連差分・計画と照合し、予定欄に置く。実績に混ぜない |
| テストファイルは追加されたが実行ログはない | テスト追加は報告できる。テスト通過・実機確認済みとは書かない |
| natural-japaneseが見つからない | 未導入と伝える。履歴の調査は可能。スキル使用済みとは言わない |
| natural-japaneseのlintが依存不足で失敗した | 依存宣言に合ったuv runを使用。利用できなければ手動チェックリストを使い、lint未実行を明記 |
| マージ、取り消し、再修正が混在する | 同じ成果を水増しせず、最終的な変更を報告する |

作成前の実例では、lintを直接Pythonで起動して `ModuleNotFoundError: No module named 'sudachipy'` が発生し、その失敗が報告文に明示されなかった。本スキルでは依存宣言に合わせた実行方法と、手動確認時の開示を明記した。
